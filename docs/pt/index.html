Dados de exemplo

O que mostra

Um cartão por cada cliente aberto, atualizado a cada segundo.

Nomes das personagens

Lê o nome por cima da tua personagem com o reconhecimento de texto integrado no Windows, para saberes qual janela é qual. Também o podes escrever tu.

Latência e tráfego

O tempo de ida e volta até ao servidor a verde, amarelo ou vermelho, mais os dados recebidos e enviados em cada ligação.

Desconexão com um clique

Corta a ligação de um cliente congelado sem fechar o jogo. Podes ligar ou desligar a confirmação.

Servidor e processo

O endereço do servidor de cada cliente, o ID do processo, a hora de arranque e a memória usada.

Não mexe no jogo

Sem injeção, sem leitura de memória, sem pacotes enviados. As capturas para ler o nome ficam só em memória e nunca são guardadas.

Código aberto

Python com licença MIT. Lê cada linha, compila tu mesmo o .exe ou envia uma correção.

Como encontra o teu nome

A câmara mantém a tua personagem no centro do ecrã, por isso o teu nome é o texto centrado logo acima dela.

  1. Captura a janelaO Windows Graphics Capture tira uma imagem de cada cliente, mesmo quando a janela está por trás de outras.
  2. Encontra a placa do nomeO reconhecimento de texto procura a palavra centrada no fim de uma placa que começa por “Lv”, seja qual for o teu título de grau ou a sua cor.
  3. Lê outra vez, mais de pertoSó o nome é ampliado e lido uma segunda vez, o que o separa do teu título.
  4. VotaçãoMonstros, números de dano e outros jogadores podem tapar o nome num fotograma. Um nome só aparece quando a mesma leitura se repete mais de uma vez.

Instalação

Transfere a aplicação

  1. Transfere o M2Monitor.exe e guarda-o onde quiseres, por exemplo em Documentos.
  2. Faz duplo clique. Se o Windows mostrar “O Windows protegeu o seu PC”, clica em Mais informações e depois em Executar mesmo assim. A aplicação não tem assinatura digital, o que é normal em ferramentas gratuitas feitas por gosto.
  3. Clica em Restart as administrator na janela para ativar a latência, o tráfego e a desconexão.

Nomes, servidores e dados dos processos funcionam sem direitos de administrador. O Windows só deixa programas com direitos de administrador ler as estatísticas de cada ligação e reiniciá-las.

Ou corre a partir do código

git clone https://github.com/IliescuM/m2monitor
cd m2monitor
python -m pip install -r requirements.txt
python m2monitor.py

Precisas do Python 3.10 ou mais recente e de um idioma com reconhecimento de texto instalado no Windows; o inglês chega. Corre build.bat para criar o teu próprio .exe.
