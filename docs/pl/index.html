Co pokazuje

Jedna karta na każdy uruchomiony klient, odświeżana co sekundę.

Nazwy postaci

Odczytuje nazwę nad twoją postacią za pomocą wbudowanego w Windows rozpoznawania tekstu, więc wiesz, które okno jest które. Możesz też wpisać ją sam.

Ping i transfer

Czas odpowiedzi serwera w kolorze zielonym, żółtym lub czerwonym oraz dane wysłane i odebrane dla każdego połączenia.

Rozłączanie jednym kliknięciem

Zrywa połączenie zawieszonego klienta bez zamykania gry. Potwierdzenie możesz włączyć lub wyłączyć.

Serwer i proces

Adres serwera każdego klienta, ID procesu, godzina uruchomienia i zużycie pamięci.

Nie ingeruje w grę

Bez wstrzykiwania kodu, bez odczytu pamięci, bez wysyłania pakietów. Zrzuty ekranu do odczytu nazwy zostają tylko w pamięci i nigdy nie są zapisywane. Działa z niskim priorytetem, więc gra zawsze ma pierwszeństwo.

Open source

Python na licencji MIT. Przeczytaj każdą linijkę, zbuduj .exe samodzielnie albo wyślij poprawkę.

Jak znajduje twoją nazwę

Kamera trzyma twoją postać na środku ekranu, więc twoja nazwa to wyśrodkowany tekst tuż nad nią.

  1. Przechwyć oknoWindows Graphics Capture robi zdjęcie każdego klienta, nawet gdy okno jest zasłonięte innymi.
  2. Znajdź tabliczkę z nazwąRozpoznawanie tekstu szuka wyśrodkowanego słowa na końcu tabliczki zaczynającej się od „Lv”, niezależnie od tytułu rangi i jego koloru.
  3. Przeczytaj jeszcze raz, z bliskaSama nazwa jest powiększana i odczytywana drugi raz, co oddziela ją od tytułu postaci.
  4. GłosowaniePotwory, liczby obrażeń i inni gracze mogą zasłonić nazwę na jednej klatce. Nazwa pojawia się dopiero, gdy ten sam odczyt powtórzy się kilka razy.

Instalacja

Pobierz aplikację

  1. Pobierz M2Monitor.exe i zapisz go w dowolnym miejscu, na przykład w Dokumentach.
  2. Kliknij dwukrotnie plik. Jeśli Windows pokaże „System Windows ochronił ten komputer”, kliknij Więcej informacji, a potem Uruchom mimo to. Aplikacja nie jest podpisana cyfrowo, co jest normalne w darmowych narzędziach robionych hobbystycznie.
  3. Kliknij w oknie Restart as administrator, aby włączyć ping, transfer i rozłączanie.
  4. Aktualizacja: zamknij M2 Monitor, pobierz nowy M2Monitor.exe i zastąp stary plik. Ustawienia zostaną zachowane.

Nazwy, serwery i szczegóły procesów działają bez uprawnień administratora. Windows pozwala tylko programom uruchomionym jako administrator odczytywać statystyki połączeń i je resetować.

Albo uruchom ze źródeł

git clone https://github.com/IliescuM/m2monitor
cd m2monitor
python -m pip install -r requirements.txt
python m2monitor.py

Wymaga Pythona 3.10 lub nowszego i zainstalowanego w Windows języka z rozpoznawaniem tekstu; angielski wystarczy. Uruchom build.bat, aby zbudować własny .exe.

Daj znać, co myślisz

Pomysły, błędy albo nazwa postaci, którą ciągle źle odczytuje: każde zgłoszenie pomaga. Potrzebne jest darmowe konto GitHub.
