Date de exemplu

Ce afișează

Câte un card pentru fiecare client pornit, actualizat în fiecare secundă.

Numele personajelor

Citește numele de deasupra personajului tău cu recunoașterea de text integrată în Windows, ca să știi care fereastră e care. Îl poți scrie și singur.

Latență și trafic

Timpul dus-întors până la server, în verde, galben sau roșu, plus datele primite și trimise pe fiecare conexiune.

Deconectare dintr-un clic

Întrerupe conexiunea unui client blocat fără să închidă jocul. Pasul de confirmare se poate activa sau dezactiva.

Server și proces

Adresa serverului folosit de fiecare client, ID-ul procesului, ora pornirii și memoria folosită.

Nu atinge jocul

Fără injectare, fără citirea memoriei, fără pachete trimise. Capturile pentru citirea numelui rămân doar în memorie și nu sunt salvate niciodată.

Open source

Python sub licență MIT. Poți citi fiecare linie, poți construi singur .exe-ul sau poți trimite o corectură.

Cum îți găsește numele

Camera îți ține personajul în mijlocul ecranului, așa că numele tău este textul centrat chiar deasupra lui.

  1. Capturează fereastraWindows Graphics Capture face o imagine a fiecărui client, chiar dacă fereastra lui e în spatele altora.
  2. Găsește eticheta cu numeleRecunoașterea de text caută cuvântul centrat de la finalul unei etichete care începe cu „Lv”, indiferent de titlul de grad sau de culoarea lui.
  3. Citește din nou, mai de aproapeDoar numele este mărit și citit a doua oară, ceea ce îl separă de titlul personajului.
  4. VoteazăMonștrii, cifrele de damage și alți jucători pot acoperi numele într-un cadru. Numele apare doar după ce aceeași citire revine de mai multe ori.

Instalare

Descarcă aplicația

  1. Descarcă M2Monitor.exe și salvează-l oriunde, de exemplu în Documente.
  2. Dă dublu clic pe el. Dacă Windows afișează avertismentul albastru SmartScreen, apasă Mai multe informații, apoi butonul care pornește aplicația oricum. Aplicația nu are semnătură digitală, lucru normal pentru programele gratuite făcute din pasiune.
  3. Apasă Restart as administrator în fereastră ca să activezi latența, traficul și deconectarea.

Numele, serverele și detaliile proceselor merg și fără drepturi de administrator. Windows permite doar programelor pornite ca administrator să citească statisticile conexiunilor și să le închidă.

Sau rulează din codul sursă

git clone https://github.com/IliescuM/m2monitor
cd m2monitor
python -m pip install -r requirements.txt
python m2monitor.py

Ai nevoie de Python 3.10 sau mai nou și de o limbă cu recunoaștere de text instalată în Windows; engleza e suficientă. Rulează build.bat ca să-ți faci propriul .exe.
