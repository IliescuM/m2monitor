Beispieldaten

Was es anzeigt

Eine Karte pro laufendem Client, jede Sekunde aktualisiert.

Charakternamen

Liest den Namen über deinem Charakter mit der in Windows eingebauten Texterkennung, damit du weißt, welches Fenster welches ist.

Latenz und Datenverkehr

Die Antwortzeit zum Server in Grün, Gelb oder Rot, dazu ein- und ausgehende Daten pro Verbindung.

Trennen mit einem Klick

Trennt die Verbindung eines eingefrorenen Clients, ohne das Spiel zu schließen. Die Bestätigung lässt sich ein- und ausschalten.

Server und Prozess

Die Serveradresse jedes Clients, seine Prozess-ID, Startzeit und Speichernutzung.

Finger weg vom Spiel

Keine Injection, kein Auslesen des Speichers, keine gesendeten Pakete. Screenshots zum Lesen der Namen bleiben im Arbeitsspeicher und werden nie gespeichert.

Open Source

Python unter MIT-Lizenz. Lies jede Zeile, baue die .exe selbst oder schick einen Fix.

So findet es deinen Namen

Die Kamera hält deinen Charakter in der Bildschirmmitte, also ist dein Name der zentrierte Text direkt darüber.

  1. Fenster aufnehmenWindows Graphics Capture macht ein Bild von jedem Client, auch wenn das Fenster hinter anderen liegt.
  2. Namensschild findenDie Texterkennung sucht das zentrierte Wort mit einer Levelangabe daneben oder einem Gildennamen darüber.
  3. Näher noch einmal lesenNur der Name wird vergrößert und ein zweites Mal gelesen. So trennt er sich von deinem Titel.
  4. AbstimmenMonster, Schadenszahlen und andere Spieler können den Namen in einem Bild verdecken. Ein Name erscheint erst, wenn dieselbe Lesung mehrmals vorkommt.

Installation

App herunterladen

  1. M2Monitor.exe herunterladen und irgendwo speichern, zum Beispiel unter Dokumente.
  2. Doppelklicke die Datei. Zeigt Windows „Der Computer wurde durch Windows geschützt“, klicke auf Weitere Informationen und dann auf Trotzdem ausführen. Die App ist nicht signiert, was bei kostenlosen Hobby-Tools normal ist.
  3. Klicke im Fenster auf Restart as administrator, um Latenz, Datenverkehr und Trennen freizuschalten.

Namen, Server und Prozessdetails funktionieren auch ohne Administratorrechte. Windows erlaubt nur Programmen mit Administratorrechten, Verbindungsstatistiken zu lesen und Verbindungen zurückzusetzen.

Oder aus dem Quellcode starten

git clone https://github.com/IliescuM/m2monitor
cd m2monitor
python -m pip install -r requirements.txt
python m2monitor.py

Benötigt Python 3.10 oder neuer und eine in Windows installierte Sprache mit Texterkennung; Englisch reicht. Mit build.bat baust du deine eigene .exe.
