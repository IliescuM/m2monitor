Datos de ejemplo

Qué muestra

Una tarjeta por cada cliente abierto, actualizada cada segundo.

Nombres de personajes

Lee el nombre que aparece sobre tu personaje con el reconocimiento de texto integrado en Windows, para que sepas qué ventana es cuál.

Latencia y tráfico

El tiempo de ida y vuelta al servidor en verde, ámbar o rojo, más los datos de entrada y salida de cada conexión.

Desconexión con un clic

Corta la conexión de un cliente congelado sin cerrar el juego. Puedes activar o desactivar la confirmación.

Servidor y proceso

La dirección del servidor de cada cliente, su ID de proceso, la hora de inicio y el uso de memoria.

No toca el juego

Sin inyección, sin leer la memoria, sin enviar paquetes. Las capturas para leer el nombre se quedan en memoria y nunca se guardan.

Código abierto

Python con licencia MIT. Lee cada línea, compila el .exe tú mismo o envía una corrección.

Cómo encuentra tu nombre

La cámara mantiene a tu personaje en el centro de la pantalla, así que tu nombre es el texto centrado justo encima.

  1. Captura la ventanaWindows Graphics Capture toma una imagen de cada cliente, incluso si su ventana está detrás de otras.
  2. Encuentra la placa del nombreEl reconocimiento de texto busca la palabra centrada con el nivel al lado o el nombre del gremio encima.
  3. Vuelve a leerlo de cercaSolo el nombre se amplía y se lee por segunda vez, lo que lo separa de tu título.
  4. VotaciónLos monstruos, los números de daño y otros jugadores pueden tapar el nombre en un fotograma. Un nombre solo aparece cuando la misma lectura se repite más de una vez.

Instalación

Descarga la app

  1. Descarga M2Monitor.exe y guárdalo donde quieras, por ejemplo en Documentos.
  2. Haz doble clic. Si Windows muestra “Windows protegió su PC”, haz clic en Más información y luego en Ejecutar de todas formas. La app no está firmada digitalmente, algo normal en las herramientas gratuitas hechas por afición.
  3. Haz clic en Restart as administrator en la ventana para activar la latencia, el tráfico y la desconexión.

Los nombres, servidores y datos de procesos funcionan sin permisos de administrador. Windows solo permite a los programas con permisos de administrador leer las estadísticas de cada conexión y reiniciarlas.

O ejecútalo desde el código fuente

git clone https://github.com/IliescuM/m2monitor
cd m2monitor
python -m pip install -r requirements.txt
python m2monitor.py

Necesitas Python 3.10 o posterior y un idioma con reconocimiento de texto instalado en Windows; con el inglés basta. Ejecuta build.bat para crear tu propio .exe.
