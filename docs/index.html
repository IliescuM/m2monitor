Example data

What it shows

One card per running client, refreshed every second.

Character names

Reads the name above your character with Windows' built-in text recognition, so you know which window is which.

Latency and traffic

Round-trip time to the server in green, amber or red, plus data in and out for each connection.

One-click disconnect

Drops a frozen client's connection without closing the game. Turn the confirm step on or off.

Server and process

The server address each client uses, its process ID, start time and memory use.

Hands off the game

No injection, no memory reading, no packets sent. Screenshots for name reading stay in memory and are never saved.

Open source

MIT licensed Python. Read every line, build the .exe yourself, or send a fix.

How it finds your name

The camera keeps your own character in the middle of the screen, so your name is the text centred right above it.

  1. Capture the windowWindows Graphics Capture takes a picture of each client, even when it is behind other windows.
  2. Find the nameplateText recognition looks for the centred word with a level marker beside it or a guild name above it.
  3. Read it again, closerThe name alone is enlarged and read a second time, which separates it from your title.
  4. VoteMonsters, damage numbers and other players can cover the name in one frame. A name shows only once the same reading comes back more than once.

Install

Download the app

  1. Download M2Monitor.exe and save it anywhere, for example in Documents.
  2. Double-click it. If Windows shows “Windows protected your PC”, click More info, then Run anyway. The app is not code-signed, which is normal for free hobby tools.
  3. Click Restart as administrator in the window to turn on latency, traffic and disconnect.

Names, servers and process details work without administrator rights. Windows only lets elevated programs read per-connection statistics and reset connections.

Or run from source

git clone https://github.com/IliescuM/m2monitor
cd m2monitor
python -m pip install -r requirements.txt
python m2monitor.py

Needs Python 3.10 or newer and an OCR language installed in Windows; English is enough. Run build.bat to make your own .exe.
